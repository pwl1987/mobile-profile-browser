# 中文优先（Chinese-first）规范

> 项目一级要求，自 2026-08-31 起生效。所有 Gate 验收包含本规范。

## 原则

**项目以中文为第一语言**：APK、UI、文档、错误提示、测试说明、Release
全部中文化；代码、API、协议保留英文技术命名。不做逐句机器翻译，面向
用户的内容按中文产品语言书写。

## 分层规则

### 面向用户 —— 必须中文

App 名称、首页、Profile 列表、创建/编辑 Profile、浏览器外壳、代理与
SSH 设置、网络状态、Runtime 状态、错误提示、Toast/Snackbar、Dialog、
空状态、Loading、权限提示、设置、关于、帮助、首次启动引导。

实现方式：`lib/l10n/app_zh.arb` 为默认资源（`app_en.arb` 可选），UI
字符串一律走 localization，**禁止** `Text("Profile is running")` 这类
硬编码。显示名中文、**APK 文件名保持英文**（如
`mobile-profile-browser-m3.4-dev.apk`）——CI/脚本/下载环境对英文文件名
最稳定。

### 面向开发者 —— 保留英文

Class / Method / Variable / Package / Repository / Adapter / Runtime /
API / Protocol / Enum / Git branch / commit message 中的标识符。

但 README、ADR、架构文档、开发文档、测试说明、Release Notes
**默认中文**，必要时在括号内保留英文原始术语。

### 领域枚举绝不直接显示给用户

内部状态与 UI 标签分离：

| 内部（enum） | UI（中文） |
| --- | --- |
| created | 已创建 |
| ready | 就绪 |
| starting | 正在启动 |
| running | 运行中 |
| stopping | 正在停止 |
| stopped | 已停止 |
| error / failed | 出错 / 启动失败 |
| degraded | 状态受限 |
| unknown | 状态未知 |
| recovering | 正在恢复 |

代码入口：`profileStatusZhLabel()`（domain）与
`webLibreRuntimeStateZhLabel()`（weblibre）。Flutter UI 落地后由
`app_zh.arb` 承接同一映射。

## 产品命名

- **产品名：独立浏览器**
- 副标题：多 Profile 隔离浏览环境
- 仓库名 `mobile-profile-browser` 与包名保持英文不变
- 决策记录见 `docs/adr/0005-product-naming-chinese-first.md`

## Release 规范

- 历史构建基线：`m1-baseline-*`（纯上游，英文注记保留，不重做）。
- 自 M3 起的开发版：tag 形如 `m3-runtime-dev-202609xx`，Notes 用
  `docs/release/release-notes-template.md` 中文模板：本版本 / 已知限制
  / 验证环境三段，如实写明 Gecko 单实例等限制。

## CI 检查

`i18n-quality.yml` 运行 `tools/check-i18n.sh`：

1. README 与 docs/**/*.md 剥离代码块后中文占比 ≥ 15%；
2. 例外文件需显式登记在脚本白名单。

Flutter UI 出现后追加：新增用户可见字符串必须进入 localization
（arb 键存在性检查）。
