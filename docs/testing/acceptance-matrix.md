## 发布规则

不能因为 UI 已经显示某个功能，就把功能标记为“完成”。每项功能必须有测试证据；如果底层引擎存在限制，则必须记录限制、影响范围和验证结果。

## 测试原则

测试必须尽量在真实 Android 设备上进行。模拟器只能作为开发和自动化测试环境，不能替代涉及浏览器存储、网络路由、VPN/TUN、电量和后台限制的最终验收。
